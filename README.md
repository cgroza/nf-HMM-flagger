# nf-HMM-flagger
Nextflow pipeline for HMM flagger


## Parameters:
- `--config`: one of the config files published in the [HMM-Flagger repo](https://github.com/mobinasri/flagger#the-current-version-of-hmm-flagger-v120-has-different-presets-for-pacbio-hifi-ont-r9-and-ont-r10)
- `--samples`: CSV file listing sample, hap1, hap2, and reads (BAM).
